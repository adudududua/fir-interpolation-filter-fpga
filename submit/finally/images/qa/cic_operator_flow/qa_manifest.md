# CIC算法级信流图质量核验

- 图形定位：算法/算子级信流图，与实现级资源映射图配套而不重复。
- 信号命名：输入采用`x8[n]`，Hold16后的高速序列采用`h[k]`，输出采用`y128[k]`，避免与原参考图入口`u[m]`混淆。
- 结构：低速二阶差分、16点零阶保持、高速二阶积分及末端定点量化。
- 位宽链：21 → 22 → 23 → 23 → 26 → 29 → 20 bit。
- 延迟记号：`z_l^-1`与`z_h^-1`分别表示一次低速与高速有效事件延时。
- 积分连接：第一积分器当前输出直接进入第二积分器，延迟仅位于各自反馈支路。
- Hold语义：每个二阶差分结果重复16个高速输出事件，不表示零插值。
- 量化：中点远离零舍入、算术右移8位并饱和至signed-20。
- 时钟边界：8Fs与128Fs均为有效事件率，全链处于同一128Fs主时钟域。
- 输出：PDF、轮廓化SVG、600 dpi白底PNG及可编辑TikZ源文件。
