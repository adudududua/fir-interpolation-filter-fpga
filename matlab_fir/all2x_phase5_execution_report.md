## 1. 执行结论

指导文件对当前资源热点的判断正确，最值得优先执行的三项为：

1. Stage 3 从 Q14 精确改写为 Q15；
2. Stage 2/3 合并两个舍入饱和单元；
3. 消除宽舍入偏置加法器，并扫描共享累加器位宽。

本轮采用指导思想，但对“直接例化 DSP48E1 完成最终舍入”做了变通：Vivado 2018.3 当前推断结果中共享 DSP 的 `USE_DPORT=0、PREG=0`，动态复用乘加与纯加模式需要显式 DSP48E1 控制，风险较高。先将舍入公式等价改写为“截断值 + 单比特进位”，并使用高位符号一致性判断饱和，已经达到更好的 LUT 和时序收益，因此没有继续引入 DSP 原语状态机。

最终 Phase 5 ACC40 候选结果：

```text
独立插值链：1379 LUT / 1015 FF / 2 DSP / 1 BRAM Tile
四档板级：  1536 LUT / 1181 FF / 2 DSP / 1 BRAM Tile
板级 WNS：  +44.892 ns
板级 DRC：  0 Error，保留既有 BRAM 异步控制警告
bitstream： 已成功生成
```

相对四档板测基线 `1817 LUT / 1182 FF`，Phase 5 板级实现减少 281 LUT，FF 基本不变。

## 3. Q15 统一

原 Stage 3 Q14 独立系数为：

```text
phase0 = [202, -1636, 9625]
phase1 = [-74, 261, 16008]
```

Phase 5 将它们全部乘 2：

```text
phase0 = [404, -3272, 19250]
phase1 = [-148, 522, 32016]
```

最大值 `32016 < 32767`，仍可使用 16 bit signed。若原累加结果为 `A`，新累加结果为 `2A`：

```text
RoundSat(A / 2^14) = RoundSat((2A) / 2^15)
```

因此 Stage 2 和 Stage 3 可以共用一个 Q15 舍入器，并保持位级等价。

## 4. 紧凑舍入数学等价

原模块对 Q15 累加值 `A` 执行：

```text
A >= 0：y = (A + 16384) >>> 15
A <  0：y = (A + 16383) >>> 15
```

令：

```text
q = A >>> 15
r = A[14:0]
```

则只需生成一个进位：

```text
正数：increment = r[14]
负数：increment = r[14] && OR(r[13:0])
y = q + increment
```

这样把 42 bit 偏置加法缩小为截断结果上的单比特进位。饱和判断也不再使用两个宽有符号比较器，而是检查输出符号位以上是否全为相同符号扩展位。

单元测试覆盖 10 万组 40 bit signed 可达累加值，以及正负中点和 24 bit 饱和边界，全部与原舍入模块 0 LSB。

测试中发现原模块在不可达的 42 bit 极值附近会因偏置加法回绕而反向饱和。Stage 2/3 严格上界小于 `2^39`，硬件不会进入该区域，因此等价验证按可达 40 bit signed 范围执行。

## 8. Vivado 实现与 DRC

Phase 5 脚本先 Reset `synth_1` 和 `impl_1`，再完整运行综合、布局布线和 bitstream，排除了复用旧网表的可能。

```text
Slice LUTs       = 1536 / 20800 = 7.38%
Slice Registers  = 1181 / 41600 = 2.84%
DSP48E1          = 2 / 90       = 2.22%
Block RAM Tile   = 1 / 50       = 2.00%
IOB              = 19 / 250     = 7.60%
MMCM             = 1 / 5        = 20.00%
WNS              = +44.892 ns
Timing           = All constraints met
DRC              = 0 Error
```

DRC 仍报告 Stage 1 RAMB18E1 使能由带异步复位的 CE 寄存器驱动的 `REQP-1840` 警告。这是 V3/V4 已存在的结构警告，并非 Phase 5 新增。后续若处理，应单独修改 CE 复位结构并重新做 BRAM bit-true 和板测，不能与本轮资源优化混在一起。
