# 全 2x Phase 5 七级 FIR 系数清单

> 对应工程版本：全 2x Phase 5 Q15 紧凑舍入 ACC40  
> 输入采样率：44.1 kHz  
> 输出采样率：5.6448 MHz  
> 总插值倍数：128 = 2^7  
> 整理日期：2026-07-12

## 1. 文档用途

本文档导出当前 Vivado 板级工程实际使用的七级 FIR 系数，用于：

- MATLAB 模型、RTL 和答辩材料之间的系数核对；
- 定点 Q 格式和插值增益说明；
- 后续更换系数或复现频率响应时作为基准；
- 防止把早期 93 tap Stage 1 或旧版 Stage 4～7 系数误认为当前版本。

实际浮点系数统一按下式换算：

```text
h_real[k] = h_int[k] / 2^FRAC_W
```

当前各级系数已经包含 2 倍插值所需的幅度补偿，因此每级系数和约等于 2，而不是 1。

## 3. Stage 1：105 tap 严格半带 FIR

### 3.1 参数与结构

- 输入/输出：44.1 kHz -> 88.2 kHz；
- 系数位宽：17 bit signed；
- 小数位：`FRAC_W = 15`；
- 完整长度：105 tap，编号 `h[0]` 到 `h[104]`；
- 对称中心：`h[52] = 32768 / 32768 = 1`；
- 所有非中心偶数 tap 为 0；
- 奇数 tap 构成 52 tap 对称滤波相；
- RTL 只保存前半 26 个独立非零系数，另一半由对称结构复用。

## 10. 为什么后四级系数完全相同

Stage 4～7 都是 2 倍插值半带级。将频率按各级自身采样率归一化后，它们承担相同形式的镜像抑制任务，因此可以复用同一个 canonical halfband7 核：

```text
H(z) = (-1 + 9z^-2 + 16z^-3 + 9z^-4 - z^-6) / 16
```

其 polyphase 形式为：

```text
偶相：[-1, 9, 9, -1] / 16
奇相：[0, 16, 0] / 16 -> 纯延时路径
```

系数 9 可以写成 `8 + 1`，所以乘 9 只需要一次左移和一次加法；乘 -1 只需要取负，不需要 DSP 乘法器。这正是 Stage 4～7 可以保持很低资源占用的原因。

## 11. RTL 一致性核对结论

当前 V4 板级链路实际使用的系数来源如下：

```text
Stage 1       -> all2x_v3_stage1_coeff_pkg.vh
Stage 2、3    -> all2x_v2_coeff_pkg.vh
Stage 4～7    -> interp2_halfband7_shiftadd_ce.v 内固定 canonical Q4 系数
```

七级均满足左右对称，因此都是严格线性相位 FIR。Stage 1 和 Stage 4～7 还利用半带结构中的零系数与纯延时相减少运算；Stage 2、3 利用 polyphase 拆分和对称配对，并在 V4 中共享一个 DSP。
