## 4. Stop/Go 原则

Phase 5B 只有同时满足以下条件才进入 DSP 内舍入：

```text
Stage 2 固定 shift = 0，最大误差 = 0 LSB
Stage 3 固定 shift = 0，最大误差 = 0 LSB
完整链固定 shift = 127，最大误差 = 0 LSB
独立链 LUT 至少减少 70
DSP 仍为 2
时序通过且最小调度余量不低于原有 4 cycle
```

若功能通过但 LUT 收益不足，则保留实验报告，不替换 V4 稳定实现，并优先转入 3 DSP Pareto，而不是继续堆叠复杂控制。
