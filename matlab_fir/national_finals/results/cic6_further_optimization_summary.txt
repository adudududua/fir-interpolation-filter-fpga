National-finals 6-DSP CIC further optimization
================================================

Accepted changes
----------------
1. Default opt_design strategy
   The five-directive scan showed that Default/Explore/AddRemap all reached
   556 LUT on the baseline netlist, versus 573 LUT for ExploreArea.
2. DSP48E1 PREG state retention
   The two hidden CIC integrator states use synchronous reset so Vivado can
   retain them in the existing DSP48E1 PREGs. Externally visible control,
   final state, valid and output registers retain asynchronous reset.
3. Combinational equalizer-to-CIC hand-off
   In serial-CIC mode only, the equalizer result is captured directly by the
   CIC input transaction, removing an otherwise redundant output register
   bank. The equalizer's default registered interface remains compatible.
4. Rotating 22-bit serial-comb history
   The three low-rate comb histories rotate across the three serial cycles.
   The DSP input therefore always reads history bank 0 and no longer needs a
   23-bit 3:1 mux. The CIC module changed from 44 LUT / 136 FF to
   18 LUT / 138 FF.
5. Exact four-bit burst counter
   burst_pending identifies the first of 16 outputs; burst_remaining therefore
   needs only four bits for values 15 down to 0.
6. Proven 41-bit Stage1 accumulator
   Sum(abs(non-zero coefficients)) = 44756. The conservative bound
   2^24 * 44756 = 750881079296 is below signed-41 maximum 2^40-1 =
   1099511627775. National-finals mode uses 41 bits; compatibility default
   remains 42 bits.
7. Compact Stage2/3 scheduler
   The two-bit stage value 2/3 became one-bit job_stage3, and the fixed MAC
   count is derived combinationally from stage and phase instead of stored.

Rejected experiments
--------------------
1. Equalizer arithmetic fused into the serial comb DSP
   RTL was bit-true but implemented at 581 LUT / 622 FF / 6 DSP: worse.
2. Whole-CIC synchronous reset
   It saved registers but failed the required asynchronous reset assertion.
3. Exact equalizer internal-width shrink
   Unit simulation passed but synthesis remained 584 LUT / 557 FF / 6 DSP,
   so there was no resource benefit.
4. Equalizer sharing the Stage2/3 DSP
   After correcting signed coefficient extension this was 0-LSB bit-true, but
   synthesis increased to 592 LUT / 558 FF / 6 DSP.
5. Explicit Stage1 DSP48 preadder
   Synthesis increased to 586 LUT / 578 FF / 6 DSP.
6. Merge burst_pending into the four-bit count
   Independent CIC equivalence failed at output sample 16, so the robust
   pending flag plus four-bit remaining count was restored.
