Accepted fourth/fifth-round changes
-----------------------------------
1. Stage1 DSP48E1 PREG accumulation
   The external ACC_W accumulator/result registers were removed. The existing
   DSP48E1 PREG now stores every M+P MAC step and the final sum. The symmetric
   sample pair uses a fabric pre-add followed by the DSP multiplier. The
   national-finals configuration remains at the proven-safe 41-bit bound.
2. Shared Stage2/3 DSP48E1 PREG accumulation
   The same PREG feedback structure replaces the external shared accumulator
   and result bank while preserving one DSP for both filters.
3. Exact DSP-resident Q15 rounding
   The otherwise idle result-commit cycle performs P+C+CARRYIN inside the DSP.
   C is fixed at +16383 and CARRYIN is asserted for a nonnegative result,
   exactly matching +16384/+16383 symmetric rounding without a sign-selected
   48-bit constant mux. Only shift and saturation remain outside the DSP.
4. Transaction-local history snapshot
   The longer Stage2/3 PREG schedule can overlap the next Stage3 input write.
   Full-chain regression exposed that reading the live head/fill state could
   select an unwritten BRAM slot. job_history_head and job_fill_count are now
   latched when the MAC transaction starts.
5. Shared Stage2/3 history read head
   After the correctness fix, duplicated stage-specific snapshot muxes were
   reduced to one history_read_head shared by both selected history banks.
6. Proven-width national-finals Stage3 output
   The flat Stage3 coefficient absolute sum is 22926. For a signed 20-bit
   input, 22926*2^19 = 12019810304 < 2^34, so a signed 35-bit MAC view is
   sufficient and the rounded Q15 value always fits signed 20 bits. The
   unreachable generic saturation comparator/mux was removed.
7. GUI/script configuration convergence
   The XPR now explicitly enables the 4-DSP serial-comb CIC, narrow Stage2/3,
   ResourceSharing=on and Default opt_design. A native synth_1/impl_1 rebuild
   matches the scripted 440-LUT/6-DSP result.

Rejected or superseded experiments
----------------------------------
1. Earlier Stage1 preadder-only rewrite
   It did not keep the whole accumulation in PREG and grew to
   586 LUT / 578 FF, so it remains rejected.
   Re-enabling the DSP48 preadder on the current PREG structure was also
   measured: 491 synthesized LUT versus 469 with the fabric pair sum. It
   remains rejected rather than being claimed as an active optimization.
2. Stage1-only and Stage2/3-only PREG candidates
   They were useful isolation experiments, but the accepted implementation
   combines both blocks and performs rounding in the DSP idle cycle.
3. Live Stage2/3 ring-buffer metadata
   Unit equivalence passed, but the full-chain test found corruption when the
   next input changed the live head during an existing MAC. It was rejected
   and replaced by the transaction snapshot.
4. ExploreArea as the formal implementation
   On the fifth-round CARRYIN checkpoint it required 475 LUT versus 451 for
   Default, so it remains rejected for the LUT-first competition deliverable.
