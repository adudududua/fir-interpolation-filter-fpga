# P1：Stage 3 Q14/Q15 标度修复签核

## 结论

旧 Route 1 / 5-DSP 版本的 Stage 3 整数系数实际是 Q14 幅度，但共享 MAC 固定按 Q15 右移。4x 节点不经过 Stage 3，因此幅度正常；8x 和 128x 节点被额外衰减约 6.02 dB。旧验收脚本分别用每个冲激响应的直流和归一化频响，因而纹波、阻带和相位全部通过，却没有检查节点绝对增益。

P1 将 Stage 3 统一为真 Q15 系数，恢复完整 38-bit MAC 视图和 signed 20-bit 饱和检查，并把绝对增益/模式间增益差加入正式门禁。修复后的 MATLAB、RTL、实现和 bitstream 均已通过。

## 系数与数据通路修复

真 Q15 的自然顺序 11-tap 系数为：

```text
[404, -148, -3272, 522, 19250, 32016,
 19250, 522, -3272, -148, 404]
```

偶、奇两相系数和均为 32764，即 `32764/32768 = 0.9998779296875`。同步修改了：

- MATLAB 位真模型的唯一权威系数函数；
- Stage 2/3 模块的分布式 ROM 和顺序系数 BRAM 后备表；
- 统一 RAMB18E1 的 `INIT_02/INIT_03`；
- RAMB18E1 原语级 96 地址期望值；
- Stage 3 输出的 38-bit 移位、符号扩展检查和 20-bit 饱和路径。

旧的 35-bit 直通捷径只对半幅 Q14 系数成立，修复后已删除。

## RTL 回归

XSim 正式回归 `10/10 PASS`：

- 统一 RAMB18E1：32 个 Stage 1 地址和 64 个 Stage 2/3 地址全部通过；
- 完整链路：冲激与固定随机序列的 4x/8x/128x 均为 0 LSB；
- CIC 串行 comb：连续、停顿和 burst 中复位共 3840 点等价；
- 完整链复位：8 个内部状态中断场景均恢复；
- 动态模式：10 次不停机切换无 runt pulse 或 X；
- 双家族时钟、ROM、均衡器、键盘和板级集成测试均通过。

## 发布判断

- 旧 `424 LUT / 6 DSP` Route 1 和 `436 LUT / 5 DSP` 版本仅保留为资源优化历史，不再是正确性发布候选；两者共享同一 Stage 3 绝对增益缺陷。
- P1 `446 LUT / 5 DSP` 是后续 CDC/复位和 N3 Hold 优化的唯一算法正确基线。
- 当前仍未完成实物板下载和仪器测量，不能把 bitstream 生成等同于物理板验证。
