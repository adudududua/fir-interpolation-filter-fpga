# Vivado 2025.2 固定 2 DSP / 4 RAMB18E1 的 LUT 优化复验

## 1. 试验目标与约束

本轮以 `XC7A35T_interp_opt_2025.2` 的 24/20/20 bit、CIC 积分器 DSP 模式 0 为对象，
在保持下列条件不变的前提下继续检验 LUT 压缩空间：

- 器件与完整板级顶层：XC7A35T-FGG484-2、`board_demo_competition_dac8_top`；
- 专用资源：2 个 DSP48E1、4 个 RAMB18E1（2 BRAM Tile）和 2 个 MMCM；
- FIR 系数、CIC 的 R/M/N、级间位宽、舍入/饱和、valid 相位、双采样率和 DAC 接口；
- 128 倍节点的连续输出能力，以及既有复位、CDC、动态切档和边界语义。

候选必须同时满足 RTL 位精确、完整板级实现、正 WNS/WHS、0 DRC Error 和资源硬约束；
仅局部仿真通过而不能保持板级吞吐的结构不进入正式候选集合。

## 2. 正式基线复验

当前生产工程保持 DSP 模式 0。2026-08-12 重新执行 Smoke 与 Release 两种 RTL 回归，
结果均为 **17/17 PASS**。Release 覆盖冲激、10 个固定随机种子、正负满量程和强
−1 dBFS 输入，共 14 组全链测试；4×、8×和128×三个节点的输出点数、valid 和数据均
逐样本一致，最大误差为 0 LSB。

Vivado 2025.2 从正式工程重新完成综合、布局布线和 bitstream，结果如下：

| LUT | FF | DSP48E1 | RAMB18E1 | MMCM | WNS/WHS | TNS/THS | DRC Error | Bitstream |
|---:|---:|---:|---:|---:|---:|---:|---:|---|
| **268** | **417** | **2** | **4** | **2** | +44.389/+0.078 ns | 0/0 ns | 0 | 成功 |

正式实现目录为 `XC7A35T_interp_opt_2025.2/tools/vivado_2025_2/results/20260812_205122`；
Smoke 与 Release 目录分别为
`matlab_fir/national_finals/_work/rtl_regression/20260812_203350` 和
`matlab_fir/national_finals/_work/rtl_regression/20260812_203646`。

## 3. 实现策略与综合指令扫描

基于同一 RTL 和同一完整板级约束执行实现策略扫描。`ExploreArea + Default` 保持
268 LUT/417 FF，是已测组合中的最低 LUT 结果；其余组合为 296～298 LUT。综合指令扫描中，
`AreaOptimized_medium` 为 269 LUT，`Default` 与 `FewerCarryChains` 均为 291 LUT，
`AlternateRoutability` 为 301 LUT。因而当前 `AreaOptimized_high` 配合既有实现策略仍为
固定资源条件下的最低实测组合。

## 4. 结构候选的位精确与物理实现结果

| 候选 | RTL 验证 | Routed LUT/FF | DSP/RAMB18 | WNS/WHS | 结论 |
|---|---|---:|---:|---:|---|
| 正式基线 | Smoke/Release 17/17；全链 0 LSB | **268/417** | 2/4 | +44.389/+0.078 ns | 保留 |
| pending 与 burst 计数哨兵合并 | 15,984 个输出；0 LSB；控制状态一致 | 271/417 | 2/4 | +44.362/+0.078 ns | LUT 增加 3，未采纳 |
| 舍入状态表示 | 15,984 个输出；定向、随机 CE 与中途复位均 0 LSB | 288/419 | 2/4 | +44.449/+0.056 ns | LUT/FF 均增加，未采纳 |
| 共享 Fabric 加法器 | 9,584 个受限节拍输出为 0 LSB | 295/418 | 2/4 | +44.834/+0.069 ns | 板级 `ce128` 连续有效时无可用空闲拍，且资源增加，未采纳 |

三项候选均经过真实综合、布局布线、时序和 DRC 检查，没有用综合估计替代 routed 结果。
共享 Fabric 加法器的局部等价只适用于存在计算空隙的输入节拍；正式板级 128 倍输出在突发期
每拍有效，因此该候选不满足原吞吐约束，不能以局部 0 LSB 结果认定为可发布结构。

## 5. 优化边界分析

在相同 24/20/20 bit 配置下，3-DSP 板测点为 239 LUT/388 FF，2-DSP 基线为
268 LUT/417 FF；撤去一颗用于末级 CIC 宽位积分的 DSP 后，LUT 与 FF 均精确增加 29。
网表层级审计表明，这 29 bit 状态及其逐拍加法由 Fabric 的 CARRY4/LUT 与寄存器承担，
形成近似一位状态对应一位 LUT 和一位 FF 的映射。该增量与资源报告一致，是当前 2-DSP
实现的主要结构性成本。

状态编码压缩已在 routed 结果中回退，跨拍共享又受到每拍连续输出的吞吐约束；在保持完整
21 bit CIC 输入域、补码模运算和周期行为的条件下，继续删除宽位状态将改变数值或接口语义。
因此，本轮只能得出下述有限结论：**在已覆盖的综合/实现策略、状态表示和受控调度候选范围内，
没有获得低于 268 LUT 且同时保持 2 DSP、4 RAMB18E1、原吞吐和位精确行为的完整板级实现。**
该结论不等同于对所有可能 RTL 结构的数学全局最优证明。

## 6. 发布与回退关系

- 218 LUT/365 FF/4 DSP：LUT 优先、已完成物理板验证；
- 239 LUT/388 FF/3 DSP：中间资源 Pareto、已完成物理板验证并建立 board-pass 标签；
- 268 LUT/417 FF/2 DSP：DSP 最小的当前生产配置，Smoke/Release、实现、DRC 和 bitstream
  均通过；其物理板状态应与单独的板测记录保持一致，不由工具结果代替。

生产 RTL 已恢复并保持 268-LUT 基线；未采纳候选没有写入正式数据通路。时间戳仿真目录、
Vivado 沙箱和候选工程均属于可重复生成的中间产物，不纳入正式发布目录。
