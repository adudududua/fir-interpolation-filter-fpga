# P3-J strong-signal permanent regression vectors

These four vectors are generated by `p3_joint_stage3_equalizer/rtl/p3_02_generate_rtl_vectors.m` from a 997 Hz, -1 dBFS, 44.1 kHz, zero-phase signed-24-bit stimulus. They permanently cover the positive flat-Stage3 peak that exposed the former signed-20 truncation wraparound.

- input samples: 2048
- expected 4x samples: 8413
- expected 8x samples: 16835
- expected 128x samples: 269440
- comparison rule: exact signed-24-bit equality, 0 LSB
- configuration ID: `NF-P3-RTL-JOINT-STAGE3-EQ-R1`

The files are copied into an isolated XSim run directory by `sim/run_national_finals_rtl_regression.ps1`; they are not read from a generated Vivado root directory.
