# Phase 7 验证补全指导采纳反馈

## 1. 结论

`phase7_fir_cic_verification_completion_guide.md` 对当前工程有直接指导意义。它准确指出了原有验证主要停留在“分段 0 LSB、数学频响和静态板级实现”，尚缺正式顶层长序列、CIC 节拍、复位、动态切档以及直接由 RTL 冲激输出提取频响等闭环证据。

本轮已经按指导完成全部 P0 自动化项目和大部分 P1 项目。唯一不能由本机自动完成的 P0 项目，是把本轮安全切档修正版 bitstream 重新下载到开发板并做动态切档复测。

## 4. 对指导内容的校正

1. 正式板级和本轮测试均显式使用 `FINAL_PRUNE_LSB=0`，不采用 CIC 模块声明中的通用默认值。
2. 8x 输出已经包含 Stage3 对后级 CIC 的预加重，在 15 kHz 和 20 kHz 分别约为 `+0.0757 dB`、`+0.1343 dB`。这是架构特性，不是最终 128x 频响失败。
3. 合法 20 bit 输入和 32 bit 全精度内部宽度下，正常测试应得到 0 次回绕。验证补码模语义需要另设内部边界单元测试，不能把“未触发回绕”写成“已覆盖回绕”。
4. 当前完整顶层复位测试为 8 个内部阶段场景，CIC 核另有 4 个 burst 场景，共 12 个定向复位场景。
5. 动态切档修复后，完整板级资源从先前 `1135 LUT / 962 FF` 更新为 `1128 LUT / 964 FF`，不能继续引用旧实现报告。

## 5. 暂缓项目及原因

| 项目 | 状态 | 原因 |
|---|---|---|
| 单入口 Tcl/MATLAB 自动回归 | 部分完成 | 向量生成、XSim 和分析均可重复运行，但尚未封装为一个失败即返回非零的总入口。当前测试日志和命令已独立验证。 |
| SAIF/VCD 活动功耗 | 暂缓 | 属于 P2 材料完善项。当前仍使用 vectorless 估算，并明确标注 `Low confidence`。 |
| post-synthesis 功能仿真 | 暂缓 | RTL bit-true、实现时序和板级静态波形已有独立证据；该项不改变当前功能结论。 |
| post-route timing simulation | 暂缓 | 当前 WNS/WHS 均有较大正裕量，且无失败端点；该项保留为发布材料增强项。 |
| N=4 参数化回归 | 暂缓 | N=4 已在资源 Pareto 阶段判定 No-Go，不是当前发布候选。 |
| 安全切档修正版实板复测 | 待人工执行 | 需要开发板、示波器和人工按键操作。本轮已生成新 bitstream。 |

## 6. 最终判断

这份指导的核心思路正确，且已经把 Phase 7 从“分段正确”推进到“正式顶层、长序列、状态恢复、动态接口、RTL 频率相位和实现结果”均有证据的状态。当前自动化验证全部通过；在把新 bitstream 下载并完成一次动态切档板测后，可以形成完整发布闭环。
